# КиноЧат

Совместный просмотр видео с чатом. Люди заходят в общую комнату, включают
видео по ссылке или из поиска и переписываются; пауза и перемотка у всех
происходят одновременно.

Один код на Flutter собирается в APK для Android и в веб-приложение (PWA),
которое на iPhone ставится через Safari → «На экран Домой».

## Что умеет

- Комнаты по коду из шести символов или по ссылке-приглашению, до 20 человек.
- Вход по имени, без почты и пароля.
- Чат в реальном времени, история, реакции-эмодзи поверх видео.
- YouTube, VK Видео, Rutube и прямые ссылки на файлы (`.mp4`, `.webm`,
  `.m3u8`) с синхронизацией. Любая другая страница открывается рядом с чатом
  без синхронизации.
- Поиск: встроенные источники и любой свой JSON API (экран «Источники»).

## Как устроено

| Где | Что |
| --- | --- |
| `lib/room_controller.dart` | Общее состояние плеера комнаты и подгонка локального плеера под него |
| `assets/player/player.html` | Страница-плеер: один протокол для YouTube, VK, Rutube и файлов. В браузере живёт в iframe, в приложении — в WebView |
| `lib/player/` | Мост между Flutter и страницей-плеером |
| `lib/services/supabase_backend.dart` | Комнаты и история в Supabase, события через Realtime |
| `lib/services/local_backend.dart` | Демо-режим без сервера: комнаты на устройстве, вкладки одного браузера видят друг друга |
| `lib/services/search.dart` | Источники поиска, описанные данными |
| `supabase/schema.sql` | Схема базы |

## Инструменты на этом компьютере

Flutter лежит в `D:\flutter`, Android SDK и JDK 17 — в `D:\Android`. В новом
окне PowerShell:

```powershell
$env:JAVA_HOME = 'D:\Android\jdk'
$env:ANDROID_HOME = 'D:\Android'
$env:PATH = "D:\flutter\bin;D:\Android\jdk\bin;$env:PATH"
```

## Сервер (Supabase)

Пока `supabaseUrl` и `supabaseKey` в `lib/config.dart` пустые, приложение
работает в демо-режиме. Чтобы комнаты работали между устройствами:

1. Создать проект на supabase.com.
2. SQL Editor → вставить `supabase/schema.sql` → Run.
3. Project Settings → API: скопировать Project URL и publishable (anon) key
   в `lib/config.dart`.
4. Пересобрать.

Оба значения рассчитаны на то, чтобы лежать внутри приложения. Комнату может
открыть любой, кто знает её код.

## Сборка

```powershell
flutter test
flutter build apk --release                       # build\app\outputs\flutter-apk\app-release.apk
flutter build web --release --base-href /kinochat/   # build\web → GitHub Pages
```

APK подписывается отладочным ключом этого компьютера
(`%USERPROFILE%\.android\debug.keystore`). Обновление поверх установленного
приложения ставится, только если подпись та же, поэтому этот файл стоит
сохранить.

Попробовать комнату в одном браузере с двух вкладок: во второй открыть
адрес с `?as=Имя` — она зайдёт как отдельный гость.

## Свой источник поиска

Экран «Источники» → «Свой API». Указываются адрес с `{query}` (и `{key}`,
если нужен ключ) и пути к полям ответа через точку: список результатов,
название, ссылка на видео, постер. Кнопка «Проверить» показывает, что
приложение нашло и будет ли работать синхронизация.

Из браузера доступны только API, которые разрешают запросы с других сайтов
(CORS). В приложении для Android этого ограничения нет.
